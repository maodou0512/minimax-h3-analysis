# 对比与定位（框架，非排行榜）

本页**故意不写未经一手来源核对的分数表**。视频生成评测高度依赖提示集、是否使用官方预处理（如 Context-IR）、分辨率路径（768p vs 2K）与人工主观偏好。

## H3 的差异化卖点（基于官方表述）

| 维度 | H3 公开主张 |
| --- | --- |
| 模态 | 文本/图/视/音统一上下文 |
| 音频 | **原生立体声**与画面同生 |
| 开源策略 | Base 开源；IR 与 2K 再生成托管 |
| 结构 | 单流稠密 ~33B + 大视觉语言模型编码器 |
| 高清路径 | In-context 2K 再生成，而非仅传统超分 |

## 建议对比维度（你自己跑分时用）

1. **音画同步**：对白唇形、脚步与画面事件对齐。  
2. **参考遵循**：Ref2VA 多图/多视频时的身份与构图保持。  
3. **运动与物理**：相机运动、流体、布料（短片 4–15s）。  
4. **文字与细节**：768p Base vs 2K 再生成前后可读性。  
5. **可控性**：无 IR 手写提示 vs 官方 IR 脚本。  
6. **成本**：本地 GPU 小时 vs API 按秒计费（以[平台定价页](https://platform.minimax.io)实时价格为准，勿沿用过期博客数字）。  
7. **许可**：商用/地域条款是否可接受。

## 与「开源视频模型」对话时的问题清单

- 对方是否开源**音频同生**，还是仅 RGB？  
- 官方最佳质量是否依赖**闭源预处理**？  
- 公开权重分辨率与演示片分辨率是否一致？  
- 推理栈是否有可复现脚本（种子、步数、CFG/蒸馏设定）？
