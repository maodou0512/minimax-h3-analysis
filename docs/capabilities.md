# 能力边界与提示系统

## 输入 / 输出能力（公开规格）

- **统一上下文**：文本、图像、视频、音频可组合理解。  
- **原生音画同生**：立体声与画面同前向，而非独立 TTS/配乐后贴。  
- **时长**：4–15 秒。  
- **分辨率策略**：开源路径以短边约 768p 为主；2K 走托管再生成。  
- **语言**：对白稳定支持 11 语种；其它语言「不同程度支持」（官方表述）。

## Context-IR 为什么重要

复杂多模态指令（多参考、剪辑意图、声画关系）很难靠短提示直接喂给 Base。Context-IR 负责：

- 解析用户意图与素材关系  
- 时间线 / 镜头级描述  
- 声景与非叙事音乐说明  
- 在不偏离原意前提下补全缺失语义  

社区若自建预处理，应对照官方 **Prompting Guidance** 与公开 case 脚本（T2VA / I2VA / Ref2VA），而不是只堆形容词。

## 安全护栏

官方说明：用户提交的文本/图像/视频以及增强后的提示会经过自动审核；疑似违法、色情或侵权等内容可能被拦截。过滤无法消灭误杀与漏检；且**不减轻**许可证下的合法使用义务。

## 能力边界（分析笔记）

适合写进评估清单的问题：

1. 长镜头一致性（15s 上限内）随参考数量如何变化？  
2. 音频：对白唇形、环境声、配乐分层是否可独立控制？  
3. 无 Context-IR 时，手写长提示能逼近官方 IR 质量多少？  
4. 2K 再生成对文字可读性、皮肤纹理、噪声模式的实际收益？

本仓库不提供未公开的内部评测表；请用可复核实验填写你的结论。
